# 클럽 마스터

구단과 선수를 직접 만들고 실제 축구 리그에 참가시켜 시즌을 진행하는 브라우저 게임입니다.

## 실행하기

`index.html`, `real-rosters.js`, `enhancements.js`를 같은 폴더에 내려받은 뒤 `index.html`을 더블 클릭하면 브라우저에서 실행됩니다. 별도 설치나 빌드 과정은 필요하지 않습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 저장소의 `index.html`, `real-rosters.js`, `enhancements.js`, `README.md`, `DATA_SOURCES.md`, `.nojekyll` 파일을 저장소 최상위에 업로드하거나 커밋합니다.
3. GitHub 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 **Deploy from a branch**를 고릅니다.
5. 브랜치로 `main`, 폴더로 `/(root)`를 선택하고 저장합니다.
6. 잠시 기다린 뒤 Pages 화면에 표시되는 주소로 접속합니다.

## 다른 정적 웹 호스팅에 올리기

GitHub Pages, Netlify, Cloudflare Pages 등 정적 파일 호스팅을 지원하는 서비스에 프로젝트 폴더를 그대로 올리면 됩니다. 진입 파일은 `index.html`이며 `real-rosters.js`와 `enhancements.js`도 같은 폴더에 있어야 합니다. 빌드 명령이나 의존성 설치는 필요하지 않습니다.

## 저장 데이터

게임 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 같은 주소와 브라우저에서 다시 열면 이어서 할 수 있습니다. 다른 브라우저나 기기와 데이터가 자동으로 동기화되지는 않습니다.

## 기능 범위

구단 상세 화면에서는 1군·2군·유망주 명단, 구단 재정 추정치, 시설 등급을 확인하고 시설을 개선할 수 있습니다. 선수 프로필은 포지션별 능력치와 시장 가치, 주급 추정치를 표시하며, 대화와 계약 제안을 지원합니다. 외부 선수와 계약하기 전 이적 의향을 먼저 확인합니다. 대시보드 순위표와 구단 관리 화면에서 리그를 각각 선택할 수 있습니다.

실제 선수 데이터와 출처 범위는 [DATA_SOURCES.md](DATA_SOURCES.md)에 정리했습니다. 이 게임에는 2025/26 기준 5개국 1부 리그 선수 3,627명이 포함되어 있습니다. 하부 리그 팀은 게임 진행을 위해 생성한 가상 구단이며 실제 참가 명단이나 최신 이적 정보를 반영하지 않습니다. 컵 대회는 게임 내 생성 방식으로 실제 참가 규정·예선·일정과 일치하지 않습니다.
## 하부 리그와 선수단

국가별 2~4부 리그도 선택할 수 있습니다. 각국 1부 리그에는 2025/26 실제 구단과 선수 데이터가 포함되어 있습니다. 하부 리그 구단은 게임용 가상 구단입니다. 이전 자동 생성 선수는 저장 데이터를 정리할 때 제거되며, 기존 구단 선수단은 실제 등록 선수만 표시합니다. 새로 창단한 구단에는 리그 국적 비율과 포지션 능력 차이를 반영한 게임용 선수단을 생성합니다. 이 선수들은 실제 선수 데이터가 아닙니다.

참고: Transfermarkt 실제 선수의 이름은 원어 표기로 유지됩니다. 이적료는 데이터에 있는 시장가치를 표시하고, 공개 주급 자료가 없는 선수의 주급과 구단 재정은 게임 추정치로 표시합니다.
