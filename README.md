# 클럽 마스터

구단과 선수를 직접 만들고 실제 축구 리그에 참가시켜 시즌을 진행하는 브라우저 게임입니다.

## 실행하기

`index.html`, `real-rosters.js`, `club-finances.js`, `enhancements.js`를 같은 폴더에 내려받은 뒤 `index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드 과정은 필요하지 않습니다.

## GitHub Pages에 배포하기

1. 저장소 최상위에 게임 파일을 업로드하거나 커밋합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**, 브랜치 `main`, 폴더 `/(root)`를 선택하고 저장합니다.
4. Pages 화면의 사이트 주소로 접속합니다.

Netlify, Cloudflare Pages 등 정적 호스팅에도 프로젝트 파일을 함께 올리면 됩니다.

## 저장 데이터

게임 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저와 주소에서 다시 열면 이어서 할 수 있습니다.

## 기능 및 데이터 범위

구단 상세 화면에서 1군·2군·유망주 명단, 게임 재정, 공개된 구단 재정 자료, 시설 등급을 확인할 수 있습니다. 실제 재정 항목에는 출처와 기준일을 표시합니다. 공개되지 않는 이적 예산과 잔여 주급 한도는 게임 시뮬레이션 값으로 구분합니다. 선수 프로필은 능력치·시장 가치·주급을 표시하고 대화와 계약 제안을 지원합니다.

2025/26 기준 5개국 1부 리그 선수 3,627명이 포함되어 있습니다. 하부 리그 팀 및 창단 팀의 생성 선수는 게임용 데이터입니다. 선수와 구단 데이터의 출처·제한 사항은 [DATA_SOURCES.md](DATA_SOURCES.md)를 참고하세요. 컵 대회는 실제 규정과 참가 자격을 모두 재현하지 않는 게임 내 토너먼트입니다.
